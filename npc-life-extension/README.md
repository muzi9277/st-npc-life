# NPC Life · 活世界（v4.0 独立原生扩展版）

让 SillyTavern（酒馆）里的 NPC 拥有独立的幕后时间线、信息差（知情账本）、传闻扩散、主动偶遇、命运钟与严格隔离的副 API 驱动。

## v4.0.0-beta.1 重大更新：彻底独立重构

- **完全脱离旧壳独立运行**：
  - 彻底移除 775KB 旧压缩大包与生理周期、恋爱数值、烟火世界动向等无关模块，重写为清晰轻量的原生 ES 模块扩展（未压缩源码仅约 150KB，体积直降 80%+）。
  - 全新独立命名空间（`npclife_v4_*`、`nl4-*`、`【NPC Life】NPC幕后生活`），即使与原版彼方并存也互不冲突。
  - **老用户无痛升级**：首次启动自动单向迁移 3.6 的副 API 配置、自定义破限段与当前聊天的 NPC / 命运钟档案（绝不修改或破坏旧数据）。
- **经典手账书签可拖动浮窗 + 小地球悬浮球（桌面 + 手机自适应）**：
  - **可拖动小地球悬浮球**：屏幕常驻精致小地球图标，支持鼠标/触屏自由拖动并记住位置，轻点即开关浮窗。
  - **可拖动 & 可缩放的彼方风书签主窗口**：保留温润墨砚/宣纸双主题与右侧竖排衬线体书签页签（**人物 / 活世界 / 接口 / 设置**），按住顶部标题栏任意拖动不锁背景，右下角可缩放，双击标题栏一键居中复位。
  - **人物**：左列人物名册 + 右侧完整幕后状态详情/编辑，完整保留自动建档 + 手动添加 / 改名自动留别名 / 暂停追踪 / 删除，带在场与已故徽章。
  - **活世界与命运钟**：支持 **死亡 / 危急 / 失踪 / 离开 / 背叛** 5 种后果，世界书增量扫描 + 手动建钟、沉浸防剧透 / 上帝视角切换、防诈尸与一键复活撤销。
  - **接口与提示词**：独立副 API 配置（支持浏览器直连与酒馆转发、火山 Ark 与 Gemini 3.8f JSON 截断容错、**一键测试连通性**、严格 0 主模型兜底）+ 自定义破限段管理。
  - **设置与诊断**：
    - **世界书按需注入**：默认全量注入，支持一键切到 **「极简动态（仅注入：位置 / 当前在做 / 当前状态）」** 或自定义勾选列——轻松搭配总结插件 / 记忆数据库 / MVU 表格不打架，同时插件内部与面板仍保留完整记录。
    - **Swipe / 删楼统一回档**：最近 10 层滑动窗口快照同时保存 NPC 卡片与活世界/命运钟状态（不让聊天文件膨胀）。
    - **最近 5 次副 API 请求诊断卡片**：直观查看耗时、Token 估算、路由与报错原因。

## 安装与更新

- **首次安装**：打开酒馆 **扩展 → 安装扩展**，粘贴本仓库地址确认即可。
  - 读写世界书与酒馆转发模式依赖「酒馆助手（JS-Slash-Runner）」；若只用浏览器直连副 API + 提示词注入，可纯原生运行。
- **3.x 老用户升级**：打开 **扩展 → 管理扩展** 点击本扩展旁的 **更新（Update）** 后刷新页面即可自动迁移配置。
