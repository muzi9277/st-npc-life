# NPC Life · 活世界（SillyTavern 原生扩展版）

让酒馆里的 NPC 拥有独立的后台时间线、信息差（知情账本 `ledger.knows`）、传闻扭曲、队列推进与按角色隔离生成。

## 前置依赖

- **SillyTavern（酒馆）**
- **酒馆助手（JS-Slash-Runner）**（需先安装并保持启用）

## 安装方式（只需安装一次）

1. 打开酒馆右上角 **扩展（方块图标）→ 安装扩展（Install Extension）**。
2. 粘贴本仓库 Git 地址并确认安装。
3. **如果你以前在「酒馆助手」里导入过旧版 `NPCLife-*.json` 脚本**：请在酒馆助手里**停用或删除旧脚本**后刷新页面，避免双开冲突。

## 如何更新（无需重新下载）

- 作者推送新版本后，打开酒馆 **扩展 → 管理扩展**，点击本扩展旁的 **更新（Update）** 即可一键升级，或在扩展设置中开启自动更新。

## v3.6.0-beta.5 变更

- **新增「精简快跑提示词」（默认开启，省 85%+ 输入 Token）**：将彼方原本约 1.5 万字的系统规则精简为约 800 字高信噪比规则（完整保留「身份锚点」、防全知、别名、核心增量字段与所有「自定义段 / 破限」插槽），大幅加快 Flash / DeepSeek 响应速度并降低截断报错；需要原版细则可在「活世界」面板一键关掉切换。
- **降低合并更新默认重试上限**：`Jr()` 默认最大尝试次数从 `3` 降为 `2`（最多重试 1 次），减少报错连发消耗。

## v3.6.0-beta.4 变更

- **彻底修复单轮发送触发多次生成钩子导致的重复请求**：酒馆每次发送会连续触发多个生成事件钩子（`makeFirst`/`makeLast` 共最多 6 次），此前 `Qe()` 每次都会重跑预算重置和隔离侧写；现已加入同轮单飞锁（`Qe._budgetKey` / `Qe._fateKey` / `Qe._isoSideKey` / `Qe._isoSidePromise`），同一次发送无论触发几个钩子只执行一次，提示词注入仍保留重放保护。

## v3.6.0-beta.3 变更

- **修复火山 Ark / 酒馆转发 `max_tokens` 与 `max_completion_tokens` 冲突报错**：遇到该报错自动去掉 `max_tokens` 无感重发一次，拦截 `[API 错误]` 文本避免白白重试 3 次，单角色隔离更新 `runOne` 禁止 3 次连环重试。
- **修复 Gemini 3.8f / Flash JSON 解析与截断报错**：兼容前后带文字/未闭合 Markdown 围栏、尾部逗号、省去「剧情时间」时的字段识别，并增强截断字符串/数组/括号的自动补全修复。

## v3.6.0-beta.2 变更

- **API 消耗直降 90%（从单轮 20+ 次降到默认 0~1 次）**：
  - 传闻扩散 `Ri()` 默认全走本地自然走样，即便开启「高级模型辅助」每轮最多仅润色 1 条（仅到达主角当前地点的传闻）；
  - 活动效果推断 `js()`、用户反馈解析 `si()` 与世界书自动扫描默认关闭，改走本地规则（0 额外请求），可按需在面板勾选开启；
  - 隔离模式默认单轮上限收紧为 3 人（可调 1~6 人）；
  - 新增「每轮副 API 上限」硬熔断器（默认 3 次，可设为 0 开启纯本地零消耗模式），顶部状态卡实时显示本轮次数。

## v3.6.0-beta.1 变更

- 新增 **命运钟 & 世界书后果（V1：死亡 / 危急 / 失踪）**：
  - 支持世界书本地关键词预筛 + 副 API 增量提取（按条目哈希去重，不重复扫描），也支持在「活世界」面板手动添加、暂停、解除与删除命运钟。
  - 按剧情时间（`YYYY-MM-DD` 差值）或时间词（如「出门2个月没回」）自动倒计时推进；到期自动触发死亡/危急/失踪，并按信息差等主角回到现场或提及相关地点人物时再揭晓。
  - 已故人物彻底防诈尸（移出隔离请求、冷场保活、主动偶遇队列，并向主模型注入禁止活人出场铁律；生前未竟队列转为现场遗留痕迹），面板提供「上帝视角 / 沉浸防剧透」切换与「复活 / 撤销」后悔药。
