# NPC Life · 活世界（v4.1 独立原生扩展版）

让 SillyTavern（酒馆）里的 NPC 拥有独立的幕后时间线、信息差（知情账本）、传闻扩散、主动偶遇、命运钟与严格隔离的副 API 驱动。

## v4.1.0 变更

- **手机端冷启动「悬浮球必显」深度修复**：
  - 彻底移除启动时阻塞 3.5 秒等待酒馆助手的串行延迟，改为就绪即挂载悬浮球与入口，酒馆助手在后台异步就位后再无痛迁移旧版设置；
  - 新增 `document.body` 显式等待、60 秒冷启动等待、失败自动重置重试锁、`APP_READY` / `CHAT_CHANGED` / `pageshow` / `visibilitychange` 及错峰自愈探测；
  - 首次打开前 3 秒完整露脸后再轻柔贴边半隐藏（适当提升可见透明度与最高层 `z-index: 2147483000`），手机端冷启动稳定可见不迷路。
- **在场暗剧本（Show, Don't Tell）+ 非上帝视角防剧透遮罩**：
  - 支持将**仅限在场** NPC 的「藏起来的打算」（最多 3 人，离场绝不泄露）以演员暗剧本注入主模型：不抢戏、不旁白泄底、只靠微表情/借口/顺路举动自然流露，一旦出现合适剧情契机（如路过相关地点）即可顺势展开行动；
  - 计划实施/暴露/放弃或伤势痊愈时，后台可显式返回 `""` / `"无"` 自动清空旧条目；
  - 「人物」面板在未开启上帝视角时自动遮罩「藏起来的打算」，轻点可临时偷看（切换角色或关闭面板自动重新遮罩）。
- **世界阻力 / 真实度三档位（柔和 / 写实 / 硬核）**：
  - 默认「柔和」几乎 0 额外消耗；切到「写实」或「硬核」仅增加约 80~180 Token、0 额外 API 请求，让 NPC 遇到立场/日程/资源冲突时自然拒绝或提条件，幕后计划也会经历真实受挫。
- **命运钟地名模糊匹配**：
  - 自动剥离「门口 / 里面 / 附近 / 大厅 / 一楼」等方位后缀（如命运钟地点「图书馆门口」可精准匹配正文「走进图书馆」），解决迟迟不触发揭晓的问题。

## v4.0.0-beta.7 变更

- **专属电脑 / 手机双端独立 UI（`自动识别 / 强制手机 / 强制电脑` 可选）**：
  - **手机端专属「左人名 · 右信息」双栏视图**：按照手机竖屏阅读习惯重排「人物」页，左侧 78px 窄栏竖排切换角色名与在场/已故徽章，右侧占满剩余全宽纵向显示字段并独立滚动，告别上下叠挤与字段折行；顶栏与底栏单行紧凑化。
  - **电脑端完整保留经典手账书签**：右侧探出竖排衬线体书签、自由拖拽/缩放窗口，桌面体验丝毫不变。
- **悬浮「小地球」贴边半隐藏（默认开启，可开关）**：闲置时自动吸附屏幕左/右边缘并向内缩进半个球体（只露出一半不挡聊天正文），鼠标悬停、拖动或轻点瞬间滑出使用。

## v4.0.0-beta.6 变更

- **注入层全面加固与透明化**：
  - 默认「全量注入」移除了极易引起主模型剧透的 `藏起来的打算`（仍保留在插件内部与面板，有需要可在自定义列手动勾选）；
  - 公开「世界近况」同步喂给主模型（传闻不上主台面），大局势与幕后行动无缝衔接；
  - 新增 **「无世界书时原生直注 NPC 状态表」**（不装酒馆助手或关闭世界书写入也能直注）与 **注入深度 Depth（0~10）** 调节；
  - 设置页新增 **「👁️ 预览当前注入给主模型的内容」**，随时查看通道 A（世界书）与通道 B（原生直注）原文与 Token 估算。
- **核心引擎严谨度修复**：
  - 修复模型只返回 `{ 编号, 状态, 结果 }` 增量关闭「未完成事项」时被丢弃或覆盖 `编号: "1"` 的问题，并修复 `近期关键事件` 未按最近 3 条 FIFO 累加的缺陷；
  - 修复单字名在场匹配、跨午夜日期取末尾日期、命运钟护理词否定语境（“没去照顾”不再误重置）、清空聊天遗留旧楼层快照、`renameNpc` 账本/队列别名同步及彼方 `提示词.自定义段` 迁移路径；
  - 浏览器直连报错时自动识别并提示跨域 CORS 排查建议。
- **手机端 & 实用工具升级**：
  - 手机端首次打开小地球悬浮球自动停靠屏幕右侧中上部（避开底部输入框与软键盘），适配横竖屏与键盘弹起；
  - 人物超过 5 人时自动显示名册实时搜索框；设置页新增 **导入聊天档案 JSON** 与 **检查线上新版** 按钮。

## v4.0.0-beta.5 变更

## v4.0.0-beta.4 变更

- **纯净「人物」面板布局**：将原人物栏顶部的 3 个运行开关（启用引擎 / 自动更新 / 自动建档）整体移至「设置」页顶部「⚙️ 核心运行开关」，「手动添加角色」挪到底部折叠栏，打开「人物」页第一眼即纯粹展示角色名册与完整幕后状态卡。

## v4.0.0-beta.3 变更

- **新增「一键获取模型列表」**：在「接口」页填写 API 地址与 Key 后点击 **「获取模型」**，即可拉取渠道可用模型并通过下拉框一键选择（仍保留手动输入）。
- **彻底修复单楼多角色漏识别（如 4 人只识别 2 人）的 4 个根因**：
  1. 默认最大输出 Token 从 `2048` 提升至 **`4096`**（并新增 `finish_reason === "length"` 截断检测与弹窗提示，不再静默截断丢人）；
  2. 自动解包模型偶尔嵌套输出的 `NPC` / `在场NPC` / `角色` 容器对象或数组；
  3. 放宽过度严格的称谓过滤（不再误杀「姐姐 / 妈妈 / 老师 / 管家 / 女仆」等固定称谓角色以及单字名角色，只屏蔽纯背景路人）；
  4. 强化提示词明确要求全量识别当楼所有在场重要角色，单字段更精炼防截断。

## v4.0.0-beta.2 变更

- **新增轻量「世界近况」（0 额外 API 请求）**：在「活世界」页支持维护最多 5 条活跃公共局势（封城/天灾/祭典等），正文出现重大公开事件时由主更新顺带记录并同轮喂给幕后 NPC，保持大环境与人物日常一致。
- **死亡系统深度完善**：
  - 支持正文危机由主更新顺带自动挂命运钟（0 额外请求，可开关）；
  - 角色死亡时自动把生前未竟约定与随身物转化为 **「现场遗留痕迹」**，揭晓死讯时交给主模型增强演出张力；未亲眼见证的幕后死亡自动埋下渐进式信息差传闻；
  - 人物名册新增专属 **「🕊️ 已故归档」** 分组（支持防剧透遮罩、查看遗留痕迹与一键复活撤销）。
- **精致滑动开关 UI + 丝滑 GPU 拖拽手感**：
  - 全部功能开关改为 **一排一个（标题 + 说明 + 右侧暖金滑动 Toggle 开关）**，清爽直观；
  - 小地球悬浮球与手账主窗口全面升级为 `rAF + translate3d` 硬件加速拖动、全指针捕获、放大缩放热区，并加入小地球左右边缘**轻磁吸贴边**与视口缩放防跑偏。

## v4.0.0-beta.1 重大更新：彻底独立重构

- **完全脱离旧壳独立运行**：
  - 彻底移除 775KB 旧压缩大包与生理周期、恋爱数值、烟火世界动向等无关模块，重写为清晰轻量的原生 ES 模块扩展（未压缩源码仅约 150KB，体积直降 80%+）。
  - 全新独立命名空间（`npclife_v4_*`、`nl4-*`、`【NPC Life】NPC幕后生活`），即使与原版彼方并存也互不冲突。
  - **老用户无痛升级**：首次启动自动单向迁移 3.6 的副 API 配置、自定义破限段与当前聊天的 NPC / 命运钟档案（绝不修改或破坏旧数据）。
- **经典手账书签可拖动浮窗 + 小地球悬浮球（桌面 + 手机自适应）**：
  - **可拖动小地球悬浮球**：屏幕常驻精致小地球图标，支持鼠标/触屏自由拖动并记住位置，轻点即开关浮窗。
  - **可拖动 & 可缩放的彼方风书签主窗口**：保留温润墨砚/宣纸双主题与右侧竖排衬线体书签页签（**人物 / 活世界 / 接口 / 设置**），按住顶部标题栏任意拖动不锁背景，右下角可缩放，双击标题栏一键居中复位。
  - **人物**：左列人物名册 + 右侧完整幕后状态详情/编辑，完整保留自动建档 + 手动添加 / 改名自动留别名 / 暂停追踪 / 删除，带在场与已故徽章。
  - **活世界与命运钟**：支持 **死亡 / 危急 / 失踪 / 离开 / 背叛** 5 种后果，世界书增量扫描 + 手动建钟、沉浸防剧透 / 上帝视角切换、防诈尸与一键复活撤销。
  - **接口与提示词**：独立副 API 配置（支持浏览器直连与酒馆转发、火山 Ark 与 Gemini 3.8f JSON 截断容错、**一键测试连通性**、严格 0 主模型兜底）+ 自定义破限段管理。
  - **设置与诊断**：
    - **世界书按需注入**：默认全量注入，支持一键切到 **「极简动态（仅注入：位置 / 当前在做 / 当前状态）」** 或自定义勾选列——轻松搭配总结插件 / 记忆数据库 / MVU 表格不打架，同时插件内部与面板仍保留完整记录。
    - **Swipe / 删楼统一回档**：最近 10 层滑动窗口快照同时保存 NPC 卡片与活世界/命运钟状态（不让聊天文件膨胀）。
    - **最近 5 次副 API 请求诊断卡片**：直观查看耗时、Token 估算、路由与报错原因。

## 安装与更新

- **首次安装**：打开酒馆 **扩展 → 安装扩展**，粘贴本仓库地址确认即可。
  - 读写世界书与酒馆转发模式依赖「酒馆助手（JS-Slash-Runner）」；若只用浏览器直连副 API + 提示词注入，可纯原生运行。
- **3.x 老用户升级**：打开 **扩展 → 管理扩展** 点击本扩展旁的 **更新（Update）** 后刷新页面即可自动迁移配置。
